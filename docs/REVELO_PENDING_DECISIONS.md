# Decisiones pendientes

| Tema                                 | Decisión o recurso necesario                                                                         | Mientras tanto                                                                     |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Documentos de transportador/vehículo | Elegir proveedor privado, permisos, formatos, límites, revisión, retención y borrado; revisión legal | No recibir documentos sensibles ni marcar verificaciones                           |
| Verificación administrativa          | Estados finales, roles de revisor, motivos y apelación                                               | El dashboard solo informa cuántas cuentas están pendientes                         |
| Evidencias fotográficas              | Almacenamiento privado, antivirus, límites y política de conservación                                | Las incidencias guardan texto; no se simula la carga privada de evidencia          |
| Cancelación/incidencias              | Quién puede cancelar por estado, confirmaciones, revisión y consecuencias                            | Se conserva la máquina actual; no se inventan sanciones ni reembolsos              |
| Pagos/finanzas                       | Términos, método, comprobantes, responsables y conciliación; pasarela solo con autorización futura   | Mostrar precio acordado como acuerdo, no como dinero pagado                        |
| Calificaciones                       | Moderación, réplica, reportes y retención                                                            | El promedio actual usa solo reseñas reales de viajes completados                   |
| Perfil público de reputación         | Definir campos visibles, moderación y tratamiento de comentarios                                     | Las reseñas solo las ven los participantes del viaje                               |
| RNDC/documentos regulatorios         | Alcance, habilitación, requisitos y validación con especialista                                      | La ficha interna no se presenta como documento legal                               |
| PDF de archivo                       | Definir si se requiere PDF server-side, firma, versión y retención                                   | Se ofrece imprimir/guardar desde el navegador, sin archivo persistido              |
| Migraciones                          | Definir estrategia de baseline y política de despliegue                                              | Desarrollo usa `prisma db push`; cambio nuevo aún no aplicado a una DB             |
| Animación React Bits/shadcn MCP      | MCP/registro no estaba conectado ni declarado en el proyecto                                         | Se usan animaciones CSS existentes y movimiento reducido; no se agrega dependencia |
| Notificaciones externas              | Proveedor y consentimiento para correo/push                                                          | Solo notificaciones internas                                                       |

El producto debe validar finalidades, consentimiento, retención y derechos sobre datos personales y ubicación con asesoría jurídica en Colombia antes de comercializarse.
