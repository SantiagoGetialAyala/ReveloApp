# Plan de Sprints

## Sprint 1 - Fundacion tecnica

- Monorepo con `apps/web`, `apps/api` y `packages/shared`.
- Next.js App Router con Tailwind y estructura de componentes.
- NestJS modular con Swagger, validacion global, CORS y Prisma.
- Prisma schema con entidades del MVP, indices y relaciones.
- Docker Compose para PostgreSQL.
- README y variables de entorno.

## Siguientes sprints

1. Usuarios y autenticacion completa.
2. Vehiculos y cargas.
3. Marketplace, mapas y postulaciones.
4. Viajes, notificaciones y dashboards.
5. Pruebas, hardening y despliegue.
